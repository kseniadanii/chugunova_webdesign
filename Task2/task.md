Создай полностью готовый учебный проект на чистом HTML, CSS и JavaScript (ES6 Modules) для практического задания:

Тема проекта:
CatHub — интерактивный дашборд любителя котов.

Суть проекта:
Это одностраничное веб-приложение в виде тематического дашборда, где пользователь может добавлять, удалять и использовать разные UI-виджеты, связанные с котами. Проект должен демонстрировать создание, управление и взаимодействие UI-компонентов с использованием принципов ООП.

Главные требования:
1. Используй только HTML, CSS, JavaScript без фреймворков.
2. Используй ES6 Modules.
3. Архитектура должна быть модульной и чистой.
4. Должен быть базовый класс UIComponent.
5. Все виджеты должны наследоваться от UIComponent.
6. Должен быть класс Dashboard, который управляет коллекцией виджетов.
7. Виджеты должны динамически добавляться и удаляться.
8. У каждого виджета должно быть независимое состояние.
9. Нужно минимум 2 виджета, получающих данные со сторонних API.
10. Код должен быть аккуратным, понятным и готовым для GitHub Pages.
11. Интерфейс должен быть красивым, современным, дружелюбным, в мягкой “кошачьей” тематике.
12. Не используй сборщики, npm, TypeScript и серверную часть. Все должно запускаться как статический сайт.

Реализуй следующие виджеты:

1. ToDoWidget
Назначение: список дел по уходу за котом.
Функциональность:
- добавление задачи
- удаление задачи
- отметка задачи как выполненной
- хранение списка задач внутри экземпляра класса
- у каждого экземпляра свой собственный список задач

2. CatFactWidget
Назначение: случайный факт о котах.
Функциональность:
- получает данные со стороннего API
- показывает текст факта
- кнопка “Новый факт”
- обработка состояния загрузки
- обработка ошибок API

3. CatImageWidget
Назначение: случайное фото кота.
Функциональность:
- получает изображение со стороннего API
- показывает картинку кота
- кнопка “Показать другого кота”
- обработка загрузки
- обработка ошибок API

4. NotesWidget
Назначение: заметки хозяина кота.
Функциональность:
- добавление заметки
- удаление заметки
- хранение заметок внутри экземпляра класса

Архитектура проекта должна быть такой:

index.html
main.js

js/
├── UIComponent.js
├── Dashboard.js
├── ToDoWidget.js
├── CatFactWidget.js
├── CatImageWidget.js
└── NotesWidget.js

styles/
├── main.css
└── components.css

Требования к базовому классу UIComponent:
- конструктор принимает config-объект с id и title
- хранит ссылку на корневой DOM-элемент виджета
- метод render() возвращает DOM-элемент
- метод destroy() корректно удаляет виджет из DOM
- метод minimize() сворачивает/разворачивает содержимое
- метод close() вызывает destroy()
- должна быть предусмотрена очистка обработчиков событий
- сделай базовые общие методы и удобную структуру для наследников

Требования к Dashboard:
- хранит массив активных виджетов
- принимает контейнер, куда рендерятся виджеты
- имеет метод addWidget(widgetType)
- имеет метод removeWidget(widgetId)
- умеет создавать экземпляр нужного класса по строковому типу
- после добавления вставляет виджет в DOM
- после удаления убирает его из массива
- логика должна быть централизованной и чистой

Требования к main.js:
- создай экземпляр Dashboard
- реализуй кнопки:
  - Добавить список дел
  - Добавить факт о котах
  - Добавить фото кота
  - Добавить заметки
- привяжи кнопки к dashboard.addWidget(...)
- организуй инициализацию приложения
- добавь несколько стартовых виджетов автоматически при загрузке страницы, чтобы интерфейс не был пустым

Требования к интерфейсу:
- сверху шапка с названием CatHub и коротким описанием
- ниже панель кнопок добавления виджетов
- ниже сетка дашборда
- используй CSS Grid для расположения виджетов
- каждый виджет должен быть оформлен как карточка
- у виджета должны быть:
  - заголовок
  - кнопка свернуть
  - кнопка удалить
- сделай мягкую, приятную палитру: светлый фон, акцентные пастельные цвета, можно добавить эмодзи/иконки котиков, но без перегруза
- адаптивность для планшета и телефона тоже желательна

Требования к UX:
- красивые состояния hover/focus
- понятные поля ввода и кнопки
- сообщения “Загрузка...” и “Ошибка загрузки”
- пустые состояния там, где это нужно
- плавные небольшие анимации карточек или кнопок
- интерфейс должен выглядеть как завершенный мини-проект, а не как голый учебный шаблон

Требования к API:
- подбери реальные публичные API, которые можно использовать без сложной авторизации, либо с demo/public endpoint
- для CatFactWidget используй API с фактами о котах
- для CatImageWidget используй API с фотографиями котов
- если выбранный API может быть нестабилен, предусмотрите fallback или понятную обработку ошибок
- код fetch должен быть современным и аккуратным через async/await

Требования к качеству кода:
- соблюдай ООП: инкапсуляция, наследование, полиморфизм
- методы и свойства должны быть логично организованы
- избегай дублирования кода
- делай читаемые названия переменных и методов
- добавь комментарии только там, где они действительно помогают
- не делай код излишне сложным
- не используй inline-обработчики в HTML
